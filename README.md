# quant_rotation - A股行业轮动量化系统

## 目标
构建一套完全由数据驱动、基于统计验证的行业轮动量化交易系统。在严格的风险预算约束下，捕捉类似“消费电子”板块的主升浪行情，实现低回撤、可持续的绝对收益。

## 核心原则
- 所有信号源于量化模型，排除主观判断与“投资价值”概念
- 交易宪法为最高规则，位于所有策略模型之上，不可修改
- 双轨并行：传统多因子实盘主线 + 深度学习GRU辅助验证
- 严格回测与样本外验证，无证据不入场

## 策略体系

### 主线：传统多因子行业轮动（实盘方向）
- 四因子综合打分：中期动量(40%)、低波动稳定性(25%)、成交量确认(20%)、景气度边际变化(15%)
- 周频调仓，持有排名前3的行业ETF；策略层等权，执行层按风控预算缩放
- 大盘风控：沪深300在200日线上方且成交额>8500亿，允许执行策略目标仓位；否则降仓/空仓
- 出场规则：排名跌出前10、跌破20日均线、大盘环境转弱

### 辅助：深度学习GRU行业轮动（模拟验证）
- 基于GRU神经网络预测行业收益率排名，选取Top3
- 严格抗过拟合：Dropout、L2正则、梯度裁剪、早停、滚动样本外验证
- 实盘前置条件：模拟盘稳定运行6个月以上，且经历趋势上涨、震荡、单边下跌三类市场环境

## 风控宪法（不可由模型修改）
1. **总风险预算**：单日VaR不超过账户权益2%
2. **策略熔断**：总回撤达15%暂停实盘至少一个月
3. **单品种隔离**：单标的最大亏损不超过总权益0.5%
4. **极端环境熔断**：沪深300单日跌超5%、成交额萎缩40%或不可抗力事件，清仓并观察3日
5. **人工干预权限**：仅可执行宪法熔断、暂停策略、等比例降仓，严禁直觉干预
6. **策略有效期**：每季样本外回测，滚动12个月夏普<0.5或为负则暂停
7. **生活隔离**：量化资金完全独立，亏损不影响12个月生活
