# 需求分析

## 原始需求

构建一套A股行业轮动量化交易系统，实现以下核心目标：

- 在最大回撤不超过18%的前提下，尽可能提高收益率
- 持有周期介于4周至6个月，属于中短线波段交易
- 仅使用场内ETF作为交易标的，不涉及个股或衍生品
- 所有交易决策由量化模型驱动，排除主观判断

## 问题本质

A股市场存在显著的行业轮动效应：在任意时间段内，总有少数行业因景气度边际变化、政策催化或资金偏好而产生持续性趋势行情，而大多数行业处于震荡或下跌状态。若能系统性地识别并配置这些强势行业，便可在不承担个股黑天鹅风险的前提下，获取超越市场基准的收益。

传统的主观投资方法存在三个结构性缺陷：

1. **信息处理瓶颈**：个人无法持续跟踪全市场数十个行业的基本面变化、资金流向与价格行为
2. **情绪干扰**：价值评估容易形成锚定心理，在趋势逆转时无法及时离场
3. **纪律缺失**：缺乏系统化的进出场规则，决策随市场情绪波动

## 解决方案逻辑

构建一套完全由数据驱动的行业轮动量化系统，核心逻辑为：

> 通过多维因子（动量、波动率、成交量、景气度变化）对全市场行业进行标准化评分，持续买入并持有趋势最强、上涨最稳的行业ETF，并在趋势衰减时按预设规则机械出场。

该方案的本质是：**将“识别强势行业并跟随趋势”这一主观交易中最难稳定执行的动作，转化为可回测、可验证、可重复的算法规则。**

## 个人优势分析

- **技术背景**：作为有开发经验的技术人员，具备搭建量化系统的工程能力，可使用Python、BackTrader、PyTorch等工具栈
- **资金定位**：小额散户，ETF免印花税、流动性好，是量化交易最友好的起步品种
- **风险认知**：明确将回撤控制置于收益追求之上，这是量化交易长期存活的根基

## 系统设计原则

1. **策略与宪法分离**：交易宪法为最高规则，不可由模型修改；策略模型只是宪法之下的执行插件
2. **证据先于实盘**：任何策略必须经过严格历史回测与样本外验证，才可进入实盘
3. **简单优先于复杂**：传统多因子轮动作为实盘主线，深度学习GRU作为辅助验证，不因技术能力而过度设计
4. **纪律优于预测**：系统不预测未来，只根据客观信号机械执行
5. **当前聚焦ETF**：在ETF生态位上完成策略闭环，待系统稳定后再评估向其他品种扩展的可行性
