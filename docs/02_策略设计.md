# A 股行业 ETF 中期趋势轮动策略设计

> 更新日期：2026-09-28
> 状态：交易设计方向已讨论；规则参数和策略有效性尚待验证。
> 用途：统一研究目标与交易逻辑，作为后续讨论和验证的依据。本稿不表示代码已经实现，也不构成启用实盘参数或自动下单的指令。

## 1. 策略定位与目标

面向个人独立投资资金，使用场内行业 ETF，研究一套以中期趋势为主要收益来源、允许持有现金、按风险预算分配仓位的多头策略。

核心交易逻辑：

> 在自身趋势满足条件的行业中选择相对强者，允许趋势持仓延续；根据波动、行业集中度和市场环境分配风险；机会不足时持有现金，趋势失效或风险超预算时退出或减仓。

预期持有周期为数周至数月，具体分布由交易规则和验证结果决定。不设置必须持满的期限，也不要求到期强制卖出。提前触发退出条件时，应按规则退出。

设计优先级为：风险边界和可执行性、扣除成本后的收益质量、交易稳定性、资金利用率。尚未设定年化收益目标、目标波动率、可接受的空仓时长或最长不创新高时间，不能据此宣称风险收益目标已经闭合。

### 收益假说与必须接受的代价

收益假说是：部分行业的相对强势和价格趋势具有持续性，策略能够在确认之后参与其中，并使趋势收益覆盖错误信号和交易成本。这是需要检验的假说。

该策略需要接受以下代价：

- 趋势确认存在滞后，通常无法买在最低点或完整参与启动阶段。
- 震荡环境可能反复产生小额亏损，趋势结束时可能回吐部分利润。
- 短期排名落后不必然意味着已有持仓失效。
- 风险约束和机会不足可能导致较长时间低仓位或空仓。
- 不承诺每个月盈利，也不预设任何市场环境下都能获得正收益。

## 2. 规则分工

各类规则应承担明确职责。是否增加一项规则，取决于它是否提供了可验证的边际价值。

| 决策层 | 回答的问题 | 设计原则 |
|---|---|---|
| 标的与行业映射 | 哪些 ETF 可以代表哪些行业机会？ | 同一行业选择代表产品，识别相似主题和重叠暴露 |
| 自身趋势资格 | 当前是否存在可以参与的趋势？ | 设置绝对趋势门槛，允许所有标的均不合格 |
| 相对强度排名 | 合格行业中优先考虑哪些？ | 以中期动量为主要排序依据 |
| 持仓保留与替换 | 已有趋势是否仍值得持有？ | 入场严格，保留适度宽松，减少边界附近反复换仓 |
| 仓位与市场环境 | 当前可以承担多少风险？ | 控制波动、集中度和组合风险，剩余资金持有现金 |
| 风险处置与恢复 | 何时减仓、暂停，以及何时恢复？ | 触发与恢复成对定义，紧急风险处置优先 |

## 3. 行业机会与 ETF 选择

### 3.1 先明确行业暴露，再选择交易工具

研究对象是行业机会，ETF 是参与机会的工具。候选数量不能直接代表独立风险来源的数量。

- 为每只 ETF 定义所代表的行业、主题及主要重叠暴露。
- 同一行业原则上选择一只代表 ETF，依据可交易性、流动性、跟踪质量和成本进行选择。
- 不因另一只同类 ETF 短期排名略高而频繁更换代表产品。
- 不同名称但暴露相似的 ETF，需要合并评估集中度；跨行业相关性也应进入组合风险评估。
- 回溯历史时，只使用当时已经上市、当时满足要求且信息可获得的产品，识别当前静态候选池可能造成的选择偏差。

### 3.2 候选资格与持仓管理分开

历史长度、数据可得性、流动性和正常交易状态决定能否新增持仓。已持有标的不再满足新增条件时，应评估减仓或退出的可执行性，仍须持续计价并管理其风险。

持仓数量上限按照行业分散需求、组合风险和资金规模确定，在独立样本检验前固定。候选不足或风险预算不允许时，持有更少行业或全部现金。不得为了达到持仓数量上限而增加相似暴露。

## 4. 趋势资格、排名与辅助信息

### 4.1 自身趋势资格

相对排名无法判断所有行业是否同时下跌。因此，新增持仓先通过标的自身的中期趋势条件，再参与排名。

趋势条件应从可解释的简单规则开始，例如中期累计收益条件，或价格相对中期均线的位置。首轮研究选择一种定义作为基线，避免同时堆叠多个含义相近的过滤器。

趋势窗口、入场门槛和持仓失效门槛需要在独立样本检验前固定。不能仅因某只 ETF 排名第一就放宽趋势条件。趋势资格回答是否允许参与，相对排名回答参与顺序，两者职责不同。

### 4.2 相对强度排名

在趋势合格的行业代表之间，以中期动量作为主要排序依据。动量观察窗口需与数周至数月的交易目标相匹配，从少量可解释的候选定义开始验证。

排名只能使用决策时点已知信息。同分处理规则应固定，避免无经济意义的次序变化引发换仓。

### 4.3 辅助信息的定位

| 信息 | 本稿推荐的职责 | 需要避免的解释 |
|---|---|---|
| 波动率 | 主要用于仓位预算和风险监测；低波选取作为独立比较项 | 低波动必然意味着上涨质量更好 |
| 成交量、成交额 | 流动性检查和行情诊断；量能信号单独验证 | 放量必然代表净流入或后续上涨 |
| 景气度、盈利变化 | 独立研究其新增解释力，明确公布时间、季节性和行业可比性 | 季度指标可以直接与短期量价信号等权混合 |

先检验趋势与动量基线，再逐项比较辅助信息的作用。只有能改善样本外净收益或风险表现的信息，才考虑进入正式交易规则。因子权重应服务于有证据支持的职责分工，不能为凑成综合评分而分配比例。

同时以低波动选取和波动率缩仓，会使组合进一步偏防守。若保留两者，应明确这种偏好及其对强势高波动行业参与度的影响。

## 5. 评估、开仓、持有与替换

### 5.1 决策节奏

常规机会评估以每周最后一个实际交易日收盘后为基线。每日收盘检查已有持仓风险与异常。日线方案不会自动获得盘中监控和即时成交能力。

收盘后形成的决策，最早在后续可交易时点执行。节假日、停牌、流动性不足或交易限制导致无法成交时，需要延后处置并保留风险暴露记录。

### 5.2 新增持仓

新增持仓须同时满足：

1. ETF 满足可交易资格，所属行业暴露符合组合约束。
2. 标的自身趋势达到入场条件。
3. 相对强度进入预先定义的入场范围。
4. 组合存在空余名额及风险预算。
5. 账户未处于禁止新增风险的状态。

无合格候选时，现金是正常结果。不得为凑足持仓数量而降低标准。

### 5.3 持仓保留与排名缓冲

已有持仓在自身趋势仍满足保留条件、排名未跌出保留范围、风险允许时继续持有。排名保留范围应宽于入场范围。

首轮研究采用较简单的替换逻辑：先按退出规则释放名额，再按新开仓条件补入。满额时，不因某个候选短期排名略高而自动替换原持仓。

“候选优势足够大即可提前替换”作为后续可选实验。若研究该规则，必须事先定义优势度量、阈值和成本要求，不能引入主观判断。

### 5.4 常规退出与仓位调整

| 触发情况 | 处理方式 | 评估节奏 |
|---|---|---|
| 自身趋势达到失效条件 | 在后续可交易时点退出 | 常规周评估 |
| 排名跌出持仓保留范围 | 退出，名额可由合格候选补入 | 常规周评估 |
| 波动、行业集中度或组合风险超预算 | 减仓至预算允许范围，必要时退出 | 每日风险检查 |
| 严重市场或账户风险事件 | 按风险规则暂停新增、减仓或清仓 | 事件可被确认时 |

普通趋势退出应与中期持有目标一致。如需研究更快的保护规则，应作为独立实验，并评价其减少损失与增加震荡退出之间的取舍。

每周评估不要求每周重新等权。小幅权重漂移可在预先定义的容忍范围内保留；预算超限和有效退出信号不受换手缓冲保护。

## 6. 仓位、现金与市场环境

### 6.1 仓位形成顺序

先确定行业候选与持仓保留结果，再按各行业的风险预算形成仓位，最后检查行业集中度、组合风险和市场环境允许的总风险。各类约束同时成立时，采用约束更严格的结果。

初始研究可比较等权与简单的波动率调整仓位。波动率调整需要避免低波标的获得过大名义仓位，不能因历史波动较小就忽略相关性、跳空或流动性风险。

单 ETF 名义上限、同类暴露上限与持仓数量共同限制资金投入，需要与收益目标和现金占比一起确定。不能将低仓位产生的低回撤全部归因于行业选择，也不能因资金闲置就放宽风险上限。

### 6.2 市场环境主要调整风险预算

行业自身趋势与市场环境分别评估。普通市场转弱主要影响新增风险和总仓位预算；极端风险仍可以触发清仓。

市场观察基准需要与候选行业的实际暴露相匹配。单一宽基指数不足以自动代表所有行业机会，指数走势、市场参与广度或流动性信息应分别验证，初始方案避免堆叠多个作用相近的环境开关。

市场成交额的定义应固定。可研究成交额相对历史水平等指标，但相对指标在长期低迷阶段也可能失真，不能假定一定优于绝对门槛。

环境转弱、恢复和仓位调整应使用预先定义的边界或确认条件，减少临界值附近反复切换。研究时应同时记录回撤、错失收益、空仓时长和恢复速度。

### 6.3 现金的角色

现金承担等待机会和降低总风险的职责。不得通过放宽趋势条件、增加相似行业或提高未经验证的仓位上限来强行提高资金利用率。

绩效比较需要明确现金收益假设，并与相近股票暴露或风险水平的简单组合比较。

## 7. 风险定义与规则优先级

### 7.1 准确理解风险预算

- VaR 是给定时间跨度、置信水平和模型假设下的损失分位估计，实际损失可以超过它。
- 波动率和 ATR 描述历史价格变化，不能保证单笔或单日最大损失。
- 压力情景描述指定冲击下的损失，不能穷尽未来所有情况。
- 回撤熔断线是触发处置的阈值，遇到跳空或无法成交时，实际回撤可能继续扩大。

例如，单只 ETF 的持仓价值全部损失时，对账户的影响等于该持仓占账户的比例，不会受此前波动率模型给出的风险估计值限制。

组合风险应反映各持仓的实际权重、波动及相关暴露，并检查行业同跌、跳空和流动性受限的情景。单标的预算不能简单解释为组合最坏损失上限。

### 7.2 与交易宪法的关系

[交易宪法](../notes/交易宪法.md)规定账户级风险边界、人工权限及暂停恢复纪律。策略只能在这些边界内分配风险，不能修改或绕过它们。

账户负责人先明确可接受损失与资金约束，再确定名义持仓限额、组合风险预算、压力情景限额和回撤触发线。每个数值必须同时注明计量口径、检查频率、触发动作及恢复条件，不能通过调参反向提高账户的风险承受能力。

本稿未将上述限额数值化。研究版本开始前必须显式固定其假设；模拟或实盘启用前必须形成完整账户风险参数表，缺失参数不能解释为无限风险额度。

短期无收益或单个滚动绩效指标变差，可以触发诊断。达到预设治理边界时按规则暂停；是否认定策略失效，需要结合收益来源、成本、市场环境和独立验证结果判断。

### 7.3 冲突处理顺序

账户与市场熔断优先于组合风险预算，组合风险预算优先于常规持仓规则，常规持仓规则优先于新开仓排名。无法确认数据或交易状态时，不新增风险，继续按异常处置规则管理已有持仓。

## 8. 暂停、诊断与恢复

暂停新增持仓、减仓和清仓是不同动作，必须在研究版本中写清触发条件和实际处置方式。

| 情况 | 首要处理 | 恢复依据 |
|---|---|---|
| 正常震荡或预期内回撤 | 按原规则运行并记录偏离程度 | 不因短期盈亏临时调参 |
| 风险预算超限 | 停止增加风险，按可执行方式降至预算内 | 风险重新满足预算和预设稳定条件 |
| 数据或执行异常 | 暂停新增风险，核实持仓、估值和订单状态；必要时执行既定应急减仓 | 异常消除，账户状态可核对，风险处于允许范围 |
| 账户回撤熔断 | 禁止新增风险，按预设措施减仓或清仓并进入观察期 | 满足事先规定的观察条件，完成复核，具备有效机会且风险允许 |
| 极端市场事件 | 按宪法执行可行的退出和观察 | 事件条件解除，满足观察期，交易和风险条件恢复 |
| 策略表现持续偏离预期 | 诊断收益来源、成本、市场环境与规则适用性；触及现有治理阈值时暂停 | 原规则的继续有效性得到支持，或修订版本通过独立验证 |

正常与异常表现的判断，应参考事先形成的收益、回撤和不创新高时间分布。单一短期指标不足以解释失效原因；触发暂停也不等于已经证明策略永久无效。

暂停后的恢复由账户负责人依据预设条件记录确认，模型不能自行解除账户熔断。恢复节奏应提前规定，可研究分阶段恢复预算；不得以追回损失为由加仓，也不能只凭暂停时间届满就恢复。

## 9. 如何判断方案值得继续

### 9.1 对照关系

验证应能分辨收益来自行业选择、持仓延续、市场环境控制，还是主要来自较低仓位。

| 研究问题 | 需要的对照 |
|---|---|
| 趋势资格是否有价值？ | 相同排名规则下，有无自身趋势门槛 |
| 排名缓冲是否改善持有体验？ | 每周强制替换与允许持仓延续 |
| 波动率调整是否有价值？ | 相同候选下，等权与风险调整仓位 |
| 市场环境控制是否有价值？ | 有无环境调节，且比较相近风险暴露 |
| 辅助信息是否值得引入？ | 动量基线与逐项加入信息后的版本 |
| 主动轮动是否值得承担复杂度？ | 简单持有、行业等权以及匹配风险水平的基准 |

先进行少量、有清楚经济含义的对照，避免搜索大量组合后只保留历史最好结果。

### 9.2 观察维度

除净收益、回撤和风险调整收益外，还需记录：交易成本、换手、持有期分布、现金占比、不创新高时间、不同市场环境表现、行业集中度、重大亏损情景，以及恢复持仓的效果。

评价使用真实可得数据、明确的可成交时点和成本假设；按时间保留独立样本，样本外结果不能反复用于选择参数。参数小幅变化后表现应具有可解释的稳定性，不能依赖单个窗口、少数行情或单一行业。

预期收益、可接受风险和空仓容忍度确定后，再形成具体的验收阈值。当前只能评价设计假说和相对改进，不能宣告满足尚未设定的投资目标。

## 10. 景气度、GRU 与后续研究

景气度和 GRU 保留为独立研究方向。模型复杂程度不代表新增收益来源，与主线使用相同量价信息和行业暴露时，也不自然形成风险分散。

研究顺序以证据为依据：先形成可解释的简单基线，再检验新增信息是否改善扣除成本后的样本外表现。

预测目标的时间跨度，应与实际决策周期和预计收益实现周期匹配；模型输出需要通过与主线一致的持仓和风险规则解释其经济价值。

模拟运行时长可用于观察操作稳定性，但不能单凭运行满若干个月就确认策略有效，也不能保证期间恰好覆盖所有市场环境。本稿不分配 GRU 实盘资金比例，不将其纳入主线执行规则。

|---|---|
| 核心方向 | 行业 ETF 中期趋势、多头、允许现金、风险预算约束 |
| 信号分工 | 自身趋势判断资格，相对动量排序，风险决定实际仓位 |
| 持仓方式 | 每周评估、持仓保留缓冲、风险处置优先 |
| 行业分散 | 合并同类和相似暴露，不以 ETF 数量替代分散程度 |
| 因子权重 | 趋势与动量构成简单基线，新增信息的作用和权重以独立验证为依据 |
| 入场与退出参数 | 趋势窗口、门槛、排名范围及确认条件尚待校准 |
| 仓位参数 | 持仓数量、名义上限、行业集中度和组合预算尚待按账户约束确定 |
| 市场环境规则 | 主要调节风险；指标、状态边界和转换条件尚待比较 |
| 风险治理 | 按交易宪法预先固定账户边界，触发处置与恢复条件成对定义 |
| 投资目标 | 年化收益预期、目标波动、空仓容忍度及不创新高容忍期尚待明确 |
| 验证状态 | 尚未据本稿完成绩效验证，不宣称已具备盈利优势 |

本稿完成的是交易设计整理。形成可以执行的研究版本前，需要将上述待确定项写成明确、固定、可检验的规则；当前不扩展为软件改造计划。

以下资料提供研究背景，不直接证明本策略适用于 A 股 ETF：

- [Moskowitz 与 Grinblatt：Do Industries Explain Momentum?](https://onlinelibrary.wiley.com/doi/10.1111/0022-1082.00146)——行业动量的历史研究依据，其样本和交易方式与本方案存在差异。

- [BIS：Market risk terminology，MAR10.17–10.18](https://www.bis.org/committees/bcbs/basel-framework/standard/mar?allChapters=true&q=PPP0QQQ&sort=PPP1QQQ&year=PPP2QQQ)——VaR 与尾部损失的定义，用于澄清风险度量的含义。
