# 量化系统架构

## 系统定位

一套完全由数据驱动、基于统计验证的行业轮动量化交易系统。不依赖主观判断，不包含“投资价值”概念，所有信号来源于因子打分或模型预测，所有进出场由预先设定的规则机械触发。

## 双轨策略并行

### 主线策略：传统多因子行业轮动
- **当前状态**：实盘方向，优先验证
- **策略逻辑**：四因子综合打分（中期动量40%、低波动稳定性25%、成交量确认20%、景气度边际变化15%），每周排名，持有前3名行业ETF，策略层等权，最终仓位由风控预算缩放
- **调仓频率**：周频（每周一开盘执行上周五排名信号）
- **大盘风控**：沪深300指数在200日均线上方且全市场成交额>8500亿，允许执行策略目标仓位；否则强制降低仓位或空仓
- **出场规则**：排名跌出前10名、跌破20日均线、大盘环境转弱

### 辅助策略：深度学习GRU行业轮动
- **当前状态**：模拟盘并行验证，暂不投入实盘
- **策略逻辑**：基于GRU神经网络，输入多维量价特征（开高低收量+衍生特征），预测各行业未来5个交易日收益率，选取预测排名前3的行业持有
- **调仓频率**：双周频或月频（待回测确定）
- **抗过拟合措施**：Dropout(0.2)、L2正则化、梯度裁剪、早停法、严格滚动样本外验证（TimeSeriesSplit，至少5折）
- **实盘前置条件**：模拟盘稳定运行6个月以上，且经历趋势上涨、震荡、单边下跌三类市场环境，并与回测表现一致

## 数据管道

- **数据源**：AKShare（免费，覆盖A股行业板块指数与ETF日线数据）
- **拉取频率**：每周五收盘后跑一次全量更新（`data_fetcher.py`）
- **板块映射**：东方财富概念板块指数 → 对应场内ETF代码，系统自动转换信号
- **基准数据**：沪深300指数，用于大盘风控与环境判断

## 回测框架

- **传统多因子**：基于BackTrader，至少回测5年历史数据
- **深度学习**：基于PyTorch，使用滚动时间序列交叉验证（TimeSeriesSplit）
- **核心验收标准**：
  - 总收益率、年化收益率
  - 最大回撤（不超过15%实盘熔断线）
  - 夏普比率
  - 不同市场环境下的分段表现（趋势上涨/震荡/单边下跌）
- **样本外验证**：回测结束后保留最后一段未参与任何优化的数据作为最终验证

## 执行架构

### 每日流程（自动化脚本或定时任务）
1. **收盘后**：更新持仓盈亏数据，检查风控规则是否触发（止损/止盈/大盘变天）
2. **开盘前**：若有触发信号，推送警报；若是调仓日，推送新的调仓指令

### 每周流程
1. **周五收盘后**：拉取最新行业数据，运行因子打分/模型预测，生成最新排名
2. **周末**：生成周报，包含排名变化、推荐板块、对应ETF代码
3. **周一开盘**：执行调仓指令

## 风控模块（独立于策略，不可被模型修改）

- **总风险预算**：组合单日VaR或压力测试亏损不得超过账户权益2%
- **单品种风险隔离**：单只ETF的最大风险暴露不得超过账户权益0.5%，仓位由ATR/波动率倒推
- **仓位硬限制**：单只ETF名义仓位上限15%；策略等权信号需按该上限和总风险预算缩放
- **总回撤熔断**：账户净值从高点回撤达15%时，暂停实盘至少一个月
- **策略出场执行**：排名跌出前10、跌破20日均线或大盘进入危险状态时，按策略规则清仓对应仓位
- **不干预铁律**：所有信号一旦触发，必须执行，不存在“再看看”

## 技术栈

| 模块 | 工具 | 说明 |
|------|------|------|
| 数据获取 | AKShare + pandas | 免费A股数据 |
| 传统策略 | BackTrader | 事件驱动回测框架 |
| 深度学习 | PyTorch + scikit-learn | GRU模型训练与验证 |
| 信号推送 | SMTP邮件 / Server酱微信推送 | 每日警报与周报 |
| 部署环境 | 本地或云服务器（可选） | 初期本地运行即可 |

## 开发阶段与验收标准

| 阶段 | 任务 | 验收标准 |
|------|------|----------|
| 基础搭建 | 环境安装、数据拉取脚本跑通 | `industry_data.pkl`正常生成 |
| 传统回测 | 在BackTrader上跑通多因子轮动 | 回测曲线、夏普比率、最大回撤可输出 |
| 深度学习 | 完成GRU模型训练与滚动验证 | 各fold验证集损失稳定收敛 |
| 模拟盘 | 双轨策略并行模拟交易 | 至少3个月作为阶段验收，记录所有信号与执行情况；GRU升级实盘需至少6个月 |
| 实盘 | 传统多因子策略小资金实盘 | 严格遵守风控铁律，不干预信号 |
