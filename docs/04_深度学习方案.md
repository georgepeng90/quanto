# GRU 独立研究备忘录

## 研究定位

GRU 是检验行业 ETF 趋势策略是否能从时序模型获得增量信息的独立研究方向。现行交易设计以自身趋势资格和相对动量排序为核心，GRU 预测不参与当前入场、换仓或风险处置，也没有预设实盘资金配额或按运行时间自动升级的路径。主线设计见[策略设计](02_策略设计.md)。

## 待检验的问题

在使用相同的可交易 ETF 池、信息截止时点、成交和成本假设时，GRU 能否比简单趋势与动量基线更稳定地识别后续强势行业？它提供的收益是否足以抵消模型复杂度、交易成本和潜在换手？模型预测的时长应与实际评估节奏及预期收益实现周期匹配；预测窗口、输入历史长度和网络结构都属于实验参数，不能先验固定。

GRU 可以尝试价格、成交量及其派生特征，但需要先确认数据质量、发布时间和可得性。量能不能被无条件解释为后续上涨；若引入景气数据，需作为单独实验核对其公布时间、修订、季节性和行业映射。

## 实验与验证

1. 先固定简单基线及评价口径：比较趋势资格加相对动量、简单持有或等权基准，与 GRU 在相近风险暴露下的表现。
2. 按时间划分训练、调参与独立测试区间。所有标准化参数只从当时可得的训练数据估计；预测与交易都必须遵守信息截止和后续可交易时点，处理目标区间重叠造成的泄漏。
3. 在训练区间内选择必要的正则化、早停等防过拟合措施，再用滚动样本外评估稳定性。模型结构与超参数应事先限制搜索范围，避免依测试集反复调整。
4. 比较扣除手续费、滑点和无法成交影响后的净收益、回撤、换手、行业集中度及不同市场环境下的表现。记录相对基线的增量价值，而不只看预测损失或排名一致率。
5. 独立样本若不能持续支持增量价值，则保留为研究结论，不将模型并入交易规则。进一步的模拟运行用于检查执行与监测，时间长短本身不能证明策略有效。

## 实施状态

本文是研究备忘录，不指定现成的 GRU 层数、特征数、预测天数或调仓频率，也不表示模型已经训练、验证或部署。仓库当前的命令行回测仍是既有多因子原型；任何研究成果要进入交易设计，须另行明确规则、风险处置及验证证据。
