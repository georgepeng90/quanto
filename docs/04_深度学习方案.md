# 深度学习行业轮动方案

## 当前定位

**辅助验证策略，非实盘主线。**

深度学习GRU模型与传统多因子轮动并行运行，用于对比验证和长期技术储备。在当前第一阶段，不投入实盘资金，仅在模拟盘中运行并积累观测数据。

## 为什么不是主线

- **回测可信度不足**：深度学习模型复杂度远高于线性打分，过拟合风险显著，需要更长的样本外验证周期才能建立实盘信任。
- **可解释性弱**：模型决策过程是黑箱，实盘中若连续出错，难以诊断原因，容易导致错误干预。
- **先简后繁原则**：传统多因子策略逻辑清晰、回测稳健、执行可靠，应优先完成从回测到实盘的闭环，再逐步引入复杂模型。

## 长期价值

深度学习的核心优势在于能从海量数据中自动学习非线性关系，捕捉传统线性因子无法识别的模式。当你完成传统策略的实盘闭环，且积累了足够的市场认知和数据后，这套模型将成为你最深的护城河。

## 模型结构

- **模型类型**：2层GRU + 全连接输出层
- **输入特征**（9维）：开盘价、最高价、最低价、收盘价、成交量、日收益率、10日波动率、MA5/MA20比值、收盘价/MA5比值
- **时间窗口**：回看过去20个交易日
- **预测目标**：未来5个交易日的行业收益率
- **输出操作**：预测收益率排名前3的行业ETF，双周频调仓

## 核心难点：过拟合风险与对抗机制

深度学习模型参数量大，极易“背诵”历史数据中的噪声规律，导致回测优异、实盘崩溃。对抗过拟合是训练过程的核心任务。**以下措施必须全部实施，缺一不可：**

| 措施 | 作用 | 实现方式 |
|------|------|----------|
| Dropout | 训练时随机丢弃神经元，强制网络学习稳健特征 | `nn.Dropout(0.2)` |
| L2正则化 | 限制权重增长，防止模型过度依赖个别特征 | `weight_decay=1e-5` |
| 梯度裁剪 | 防止梯度过大导致训练不稳定 | `clip_grad_norm_(max_norm=1.0)` |
| 早停法 | 验证集损失不再下降时提前终止训练 | `patience=10` |
| 滚动样本外验证 | 模拟真实预测场景，杜绝用未来信息调参 | `TimeSeriesSplit(n_splits=5)` |
| 样本外测试集 | 回测末尾保留至少1年数据，完全不参与任何优化 | 最终验收用 |

## 训练与验证流程

1. **特征工程**：从原始OHLCV数据构建9维特征，MinMaxScaler归一化
2. **数据划分**：按时间顺序进行5折滚动交叉验证，每折的测试集都是训练集的未来
3. **训练**：每折独立训练，启用上述所有抗过拟合措施
4. **验收**：各折验证集损失稳定收敛，且样本外测试集表现与验证集一致
5. **失败处理**：若验证集损失不收敛或样本外表现远差于训练集，说明模型过拟合或特征无效，需重新设计

## 与传统多因子的关系

- **数据共用**：两个策略使用同一份行业日线数据
- **信号并行**：每周同时生成传统多因子排名和GRU预测排名，分别记录
- **对比验证**：观察两者在相同市场环境下的推荐一致性。一致时增强信心，持续分歧时需分析原因
- **信任积累**：GRU模型需在模拟盘中至少运行3个月，经历趋势上涨、震荡、单边下跌三种环境，且表现稳定后，才考虑分配小资金验证
