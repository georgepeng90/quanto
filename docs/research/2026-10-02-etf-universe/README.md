## 文件

- `ETF编号表.csv`：代码、名称、研究分组、上市日期、目录规模估计、最近单日成交额、综合排序、标的指数、交易所及资料来源。CSV使用UTF-8 BOM，可由Excel读取。
- `candidates.json`：同一327只名单的结构化元数据，保留人民币数值、六位字符串代码、筛选说明及待办状态。
- `分组统计.csv`：20个分组的数量。
- `行业覆盖核对.csv`：31个行业的名称/指数关键词核对及缺口；不是成分股穿透或独立风险暴露统计。
- `待分类观察名单.csv`：另31只通过基础门槛、但尚不能可靠分类的ETF，未加入327只名单。
- `sources.json`：公开资料、用途、原始目录文件位置及SHA-256。

可筛选Excel副本位于 `outputs/etf-expansion-20261002/ETF编号表.xlsx`。原始公开目录和历史份额资料也保留在该输出目录，避免将生成文件和行情响应混入Git。

## 筛选依据

1. 保留沪深场内股票ETF。上交所使用官方分类 `F111/F112/F114/F115`，深交所使用“ETF”和“股票基金”。结合名称与指数排除跨境、债券、货币和商品暴露。
2. 上市日期不晚于2026-03-31，目录规模估计至少2亿元。上交所使用目录的亿元字段；深交所使用当前份额乘净值。官方接口未给出最新规模的估值日期，不能认定为同一估值日的严格净资产排名。
3. 2026-09-30最近单日成交额至少100万元，作为宽松的候选发现条件。最终资格拟要求经单位核验的最近60交易日日均成交额至少1000万元，当前尚未执行。
4. 规模与单日成交额按降序排名，取平均后排序。不按过去涨幅选优。先在每个行业分组保留最多4个代表，再补充排名较高的产品，每组最多30只。
5. 上交所同一官方标的指数最多保留4只。深交所当前名录没有指数字段，不能声称已经完成跨发行人的同指数去重。名称或指数含红利、价值等风格词时，行业属性仍优先。

基础预筛且分类明确的候选有580只，应用分组及同指数限制后保留327只。限额用于控制代表性，不是交易所质量标准。消费、金融、科技等大类还包含细分主题，后续回测须继续按相关暴露控制集中度。
