# PPO 环境 CPU 优化验证

本次优化复用同一环境/篮子的行情、交易状态、资格与日历索引，按需缓存每日开收盘报价，避免 episode 重置时重复准备。已有 datetime 历史列不再重复解析。每个 episode 仍重新创建账户、订单、风控、公司行动权益和奖励状态；观察公式、随机采样、事件输出、历史隔离、训练参数及验证规则保持不变。

缓存仅用于环境实例内固定的数据集和篮子，与既有历史特征缓存采用相同前提，不跨环境共享。

## 真实数据对比

使用既有 32 ETF 奖励对照的冻结数据和训练配置，基线为 `35953af`。固定 seed=42，后续 episode 不重复设 seed；动作依次覆盖 Hold、目标配置、减仓和退出，无网络更新。训练路径每种奖励 8 个 episode / 206 个决策步，收集账本路径每种奖励 2 个 episode / 51 个决策步。

| 路径 | 优化前 | 优化后 | 环境模拟提速 |
| --- | ---: | ---: | ---: |
| 净对数收益，`collect=False` | 18.076 秒 | 5.630 秒 | 3.21 倍 |
| DSR，`collect=False` | 17.535 秒 | 5.356 秒 | 3.27 倍 |
| 净对数收益，收集账本 | 5.955 秒 | 2.937 秒 | 2.03 倍 |
| DSR，收集账本 | 5.713 秒 | 2.874 秒 | 1.99 倍 |

首次 reset 仍需准备索引；训练路径后续 reset 的中位数分别从 914.0 / 1017.5 毫秒降至 15.56 / 14.25 毫秒。

四种路径的逐步观察、奖励、终止状态、info、累计奖励诊断、采样起点及收集账本哈希全部一致。原始记录保存在 [benchmark-results.json](benchmark-results.json)。计时包含 reset、推进与验证哈希，不包含读取数据及环境构造；这是本机单次环境模拟对比，不是完整 PPO 训练或 GPU 占用测量。

在仓库根目录复跑（只读冻结数据，输出独立计时文件）：

```powershell
.venv\Scripts\python.exe docs\research\2026-10-06-ppo-cpu-optimization\benchmark.py --output outputs\ppo-cpu-20261006\repeat.json
```
