# 研究文件与 Git

仓库保留人工编写的研究方法、数据来源、实验配置和精简结论，以及代码和测试实际引用的固定资料。

训练产生的逐轮指标、checkpoint 核验记录、完整回测结果、图表和本机运行状态放在已被 Git 忽略的 `outputs/`；模型和工作台数据存放在已忽略的 `data/`。保存模型 checkpoint 不等于创建 Git commit，不按训练轮数或回测节点提交。

历史文件中有脚本与测试正在引用的协议和数据来源清单，因此不对整个 `docs/research/` 统一忽略或删除。今后只在方法、配置或结论形成可审查的变化时提交必要文件，不把整批运行产物加入仓库。
