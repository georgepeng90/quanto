# 行情存储与回测数据复用设计

用户已认可 SQLite 管元数据、Parquet 管回测行情、CSV 作为交换格式，并要求先量化读取、校验和快照开销。目标是降低反复回测的重复成本，同时保留历史记录、数据版本和策略语义。

## 范围与选择

采用现有 SQLite 加 Parquet 文件，不引入数据库服务或新依赖。相比全部改为 SQLite，本次保留既有文件校验与离线研究边界；相比仅替换 CSV，同时消除逐运行复制数据的问题。原始按标的下载缓存暂留 CSV，是否改造由测量决定。

新登记的数据版本以及演示、导入、获取任务成功发布的数据表统一写为 Parquet。CSV/Parquet 导入均接受，CSV 报告导出继续提供。旧数据版本、旧快照、旧报告不改写。现存工作区不自动迁移，也不启停旧预览。

## 数据流与接口

1. 外部数据在登记/数据作业发布前执行完整结构、覆盖、状态和事件验证。
2. `quanto.data.storage.write_parquet_dataset(bundle: DatasetBundle, destination: Path) -> None` 将已验证的六张基础表及声明的辅助表写到空目标目录，更新 manifest 中辅助表文件名；保留来源和价格语义。日期、代码前导零、布尔、空事件表及 UTC available_at 均须往返一致。Parquet 行情按 symbol/date 排列，并使用有界 row group 以支持过滤；读取仍恢复协议要求的顺序。
3. 已登记的数据保留 SQLite 中的版本 ID、内容哈希和路径。新运行使用独立共享对象 `dataset_objects/<content_hash>/`，首次以暂存目录原子发布，随后复用。旧 CSV 版本可按原字节进入共享对象，不强制改写旧版本。注册目录后续被修改不得悄悄改变已冻结对象。
4. 运行 manifest schema v2 的 `files` 只包含运行专属代码/依赖说明，另有 `dataset_ref`，包含版本 ID、内容摘要和精确文件哈希映射。路径由工作区和规范摘要推导，不接受任意路径。SQLite 结构版本保持 1。
5. `quanto.data.loaders.load_dataset_for_run(path: Path, spec: BacktestSpec) -> DatasetBundle` 仅用于已完整验证且已通过哈希检查的数据。Parquet 在读取时过滤；旧 CSV 读取后过滤。价格取所选标的、数据起点到 spec.end；保留全部起点前历史。基准、状态按实际计算需要保守裁剪；交易日历、辅助表和所选标的事件先完整保留以避免跨边界语义丢失。标的注册表保持完整。不要对切片调用要求全覆盖的 validate_dataset。
6. 资格基于所选标的完整历史至结束日计算，保留累计历史数和 20 日成交额规则。策略协议不改变，warmup_bars 不是最大历史访问范围。
7. 同一批次的相同数据版本只做一次结构加载/验证与对象准备；缓存限于一次提交，不跨请求持有 pandas 数据。运行前仍逐文件完整性核验，明确保留这项 I/O，不声称所有读取都按区间缩减。

## 完整性与旧记录

共享对象采用内容摘要寻址、精确文件集合及流式哈希验证，拒绝符号链接、路径穿越、缺失、额外文件、文件篡改和未知 schema。并发发布同对象时验证后复用，不能覆盖已存在对象。发布或数据库提交失败不得暴露部分入队批次；允许留下尚未引用的完整对象，本次不增加清理功能。

旧 schema v1 保留原嵌入 dataset 路径和冻结 worker 执行路径；verify、历史 clone 和 rerun 继续支持真实旧记录。新 v2 使用共享对象和按需读取。精确重跑仍受原有环境一致性限制；此限制不得假装已消除。导出报告和指标定义不变。

## 验证与测量

- 格式基准：固定种子合成 100 标的×2500 工作日，CSV、Parquet、SQLite 的相同类型全表/5 标的末 250 日读取；预热一次，测三次中位数，验证值一致，记录文件大小。
- 流程基准：相同合成数据测完整 load_dataset、注册、连续两次 freeze、运行前校验/加载以及快照数据字节。分别报告阶段，不能把格式读速比当作整体回测速比。
- 行为回归：CSV/Parquet 往返、前导零、空事件、辅助文件、累计资格、长历史策略、预热、停牌、跨边界分红/拆分、周末后继日历；全量加载和切片加载的交易与报告等价。
- 快照回归：重复数据只发布一个对象、批次失败原子性、对象篡改/缺失/非法路径拒绝、真实 worker 执行、v1 历史校验与重跑路径、v2 精确重跑与历史 clone。
- 测量为本机合成数据、文件系统热缓存，不代表真实源数据准备完成或实盘表现。

## 交付边界

代码在独立 worktree 开发，适用验证后分阶段 commit，完成后合回用户指定的 v2，不 push。旧预览及其数据不动。文档说明新旧存储位置、共享对象必须随工作区备份，以及不能删除仍被引用对象。
