# A 股共享行情库修正

用户明确要求真实 A 股行情不随实验工作区变化；历史 CSV 正确迁移后删除，保证当前存储入口唯一。本次是对已实现行情模块的修正，沿用 Parquet、catalog、来源证据、快照和预缓存契约。

## 存储边界

- `quanto.data` 管理机器上的共享行情根。默认用户配置为 `~/.quanto/market.json`，其中 `root` 必须是绝对路径；无配置时使用 `~/.quanto/market`，与当前目录、Git checkout、工作区无关。本机配置为 `D:/Projects/quanto/data/market`。
- 工作区只管理实验、策略、回测数据包和产物。移除工作区 `market_root` 的读取与写入；获取任务仍冻结模块解析出的绝对行情根，以保证任务与来源验证一致。
- 生产管理脚本使用共享根；测试和合成基准可显式传临时根。`QUANTO_MARKET_CONFIG` 仅用于隔离配置文件，测试子进程必须继承测试配置，不能污染真实行情。

## 历史迁移

- 迁移 61 个 CSV：旧 32 ETF 与 CSI300，腾讯 27 ETF 与 CSI300。逐个校验既有审核 SHA-256，保存原始字节为内容寻址 evidence，并验证标准化 Parquet 的每行、字段、字符串标的、日期和数值。
- 真实下载时间已知的腾讯记录使用窗口记录时间；旧文件只有导入时间，须明确标记未知下载时间。单位、复权、可知时间未知仍为未知，不伪造 verified_adjusted 或真实交易状态。
- 不同冻结复权口径保留独立语义身份。同一标的默认活动序列采用较新的有记录腾讯版本，旧版本对象和证据保留；只有旧来源的标的仍活动。不能把不同复权序列拼接。
- 模块增加按哈希读取并验证来源证据的接口，供来源审计使用。迁移报告记录原路径/哈希到 fragment/evidence 的映射，冻结研究审核 JSON 不改字节；历史路径在报告中明确退役。
- 不从 CSV 猜造官方日历或 ready。所有数据已入库与完整需求已预缓存是不同状态；回测仍须通过日历及质量门槛。
- 只有全部迁移验证通过，才删除跟踪的 `data/raw` 和其目录属性文件；删除单独提交。既有回测副本和报告不改写。

## 验收

两个不同工作区解析同一共享根且重复预缓存复用数据；配置更改不破坏已提交任务的来源验证；测试不会写入真实根。61 个源文件原始字节及标准化值校验全部通过，重复迁移幂等，任何哈希或值差异阻止清理。更新当前文档入口，合并到 v2；保留并行任务的未跟踪文件。
