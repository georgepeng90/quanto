# 交易宪法：账户风险与执行纪律

> 更新日期：2026-09-28
> 定位：当前交易设计的账户级约束，与 [策略设计](../docs/02_策略设计.md)共同使用。
> 状态：治理原则确定；账户风险限额与触发参数需要在研究或交易版本启用前明确。本文件不表示现有程序已经实现这些约束。

## 1. 适用原则

交易资金独立于生活开支、应急储备和其他必要资金。账户负责人先确定可以承担的损失，再研究在该风险范围内是否存在值得执行的策略。

策略负责提出候选和目标持仓，账户风控决定允许承担的实际风险。策略模型不得修改风险边界、解除账户暂停状态，或通过拆分标的、行业、策略来重复使用同一风险额度。

纪律约束持续有效。具体估计方法和规则参数允许依据证据修订，但必须形成新的明确版本并完成验证；禁止因近期亏损、错过行情或主观判断而临时放宽边界。

## 2. 风险度量的含义

风险估计与实际损失之间存在模型误差，必须分别记录。

| 度量 | 表达的含义 | 使用边界 |
|---|---|---|
| 名义仓位 | 持仓市值占账户权益的比例 | 决定直接资金暴露，不等于波动风险 |
| 波动率或 ATR | 历史价格变化的尺度 | 不能保证下一期波动，也不是最大亏损 |
| VaR | 指定时间跨度和置信水平下的损失分位估计 | 可能被突破，不能描述所有尾部损失 |
| 压力情景损失 | 在明确价格与流动性冲击下的账户损失 | 只覆盖设定情景，不穷尽未来事件 |
| 账户回撤 | 账户净值相对历史高点的下降幅度 | 属于已发生损失的衡量，触发处置后仍可能扩大 |

所有风险限额须注明账户权益口径、时间跨度和估计方法。金额、比例、日波动和年化波动不得混用。使用 ATR 倒推仓位时，须明确价格单位、持仓数量及风险金额之间的关系。

账户权益以持续、可核对的持仓估值与现金为基础，纳入成本，并按统一方式处理资金转入转出。不得通过重启策略、重置高点或更换报告起点来解除回撤约束。

## 3. 启用前必须明确的账户参数

下列项目构成同一份风险参数表，由账户负责人根据资金用途和损失承受能力确定。研究实验可使用显式假设，但不能据实验收益反向扩大真实账户的承受范围。

| 项目 | 必须明确的内容 |
|---|---|
| 资金范围 | 可投入资金、必要资金隔离方式、允许的资金调整 |
| 总风险预算 | 风险度量、时间跨度、估计方法、预算上限与检查频率 |
| 持仓限额 | 单 ETF、同类行业、相似主题和账户总仓位的名义上限 |
| 压力情景 | 行业共同下跌、跳空、相关性上升、流动性受限等情景及可接受损失 |
| 回撤规则 | 告警和暂停触发线、触发后减仓或清仓动作、执行受限时的处置 |
| 市场异常规则 | 可观察的触发条件、数据口径、确认方式和风险动作 |
| 策略复验 | 复验周期、绩效偏离告警与暂停条件、所需诊断证据 |
| 恢复规则 | 观察条件、异常解除证据、重新验证要求和仓位恢复节奏 |

本文件不预设未经确认的最优数值。参数缺失不能视为不设限额；形成完整参数表之前，不据本方案启用模拟交易决策或实盘交易。

## 4. 单标的、行业与组合风险

单标的仓位需要同时满足名义上限与波动风险预算。低历史波动不能成为无限放大仓位的理由。

同一行业的多个 ETF、相似主题以及不同策略对同一暴露的推荐，需要合并计算。持有不同代码不自然构成风险分散。

组合风险基于实际持仓权重、波动及相关暴露进行评估，并辅以压力情景。不得将各标的风险估计机械相加后称为组合最大可能亏损，也不得忽略集中暴露。

预算超限时，优先停止新增风险，并在可交易条件下减至允许范围。可通过减少仓位、减少集中暴露或退出持仓处置；不得为降低估计值而临时更换风险模型。

## 5. 每日检查与异常处置

日线方案至少在每日收盘后检查账户权益、持仓、风险预算、回撤和交易状态。常规每周机会评估不得替代每日风险检查。

收盘信息触发的交易，最早在后续可交易时点执行。实际执行受限时，记录未完成处置及仍然存在的风险，不假定已按目标价清仓。

遇到数据缺失、估值异常、订单或持仓状态无法核对时：

1. 暂停新增风险。
2. 核对可靠价格、实际持仓、现金及订单状态。
3. 持续记录已有风险，不因缺失报价就将持仓价值视为零。
4. 根据预先制定的应急规则处置；不凭不可靠数据生成新的择时信号。

盘中事件需要事先明确监控能力与人工应急职责。日线数据无法提供盘中即时处置保证。

## 6. 回撤与极端市场事件

回撤达到预设暂停线时，禁止新增风险，并按已规定的减仓或清仓措施进入观察状态。暂停动作不能只表现为停止程序而无人管理原有持仓。

极端市场事件包括预先定义的异常价格变化、流动性恶化或交易机制受损等情形。量化触发必须明确阈值、观察窗口和数据口径；无法量化的重大事件由账户负责人记录可核实事实及采取的紧急减险动作。

任何熔断线都是处置触发条件，不是损失保证。跳空、交易限制和流动性不足可能使实际损失超出触发线。

## 7. 策略偏离与有效性复验

根据事先规定的周期复验策略，并在表现明显偏离预期时启动诊断。诊断至少区分：

- 趋势策略在震荡等不利环境中的正常表现。
- 成本、流动性和交易执行变化。
- 数据口径或决策信息发生变化。
- 行业机会、相关性或策略收益来源发生变化。

连续一段时间无收益或单个滚动指标变差，可触发检查；不能单凭这些现象断定策略永久失效。达到预设账户或治理边界时仍须暂停，诊断过程不能成为延迟风险动作的理由。

规则修订应使用明确的研究样本与独立验证，不反复根据最近的亏损调整参数。研究未支持继续运行时，保持暂停或退役。

## 8. 恢复与退役

每一种暂停都应对应明确的恢复条件。恢复至少要求：

1. 触发原因已解除或已采取有效处理措施，账户和持仓状态可以核对。
2. 满足事先规定的观察条件，并完成与暂停原因相匹配的复核。
3. 原规则仍有继续使用的依据，或修订版本已通过独立验证。
4. 当前存在符合策略条件的机会，拟恢复仓位满足全部风险限额。
5. 账户负责人记录恢复依据、规则版本和恢复节奏。

不得仅因观察时间届满、市场反弹或希望追回损失而恢复。可采用事先定义的分阶段恢复预算；模型不得自行解除账户熔断。

恢复后风险边界再次触发时，按相同规则处置。持续缺乏有效性证据或无法满足资金约束的策略，应退役，不通过更换名称或重置历史回避问题。

## 9. 人工权限与变更纪律

人工可以执行规则要求的减险动作，因账户资金约束减少风险，或在可核实的异常事件中采取紧急减险措施。每次干预记录原因、时间、持仓影响及适用规则。

禁止凭感觉增加仓位、临时取消退出信号、放宽风险限额，或用另一策略补回暂停策略的风险暴露。

账户负责人可以发起风险政策修订。修订需要给出资金约束或研究依据、明确参数含义、评估与其他规则的冲突，并在启用前固定新版本。模型可以提出研究建议，不能代替账户负责人接受更大的损失风险。

## 10. 资料与关联文件

[策略设计](../docs/02_策略设计.md)定义机会选择和持仓逻辑；本文件规定其必须遵守的账户边界。规则发生冲突时，账户风险约束优先。

VaR 和尾部损失的概念参照 [BIS 市场风险术语 MAR10.17–10.18](https://www.bis.org/committees/bcbs/basel-framework/standard/mar?allChapters=true&q=PPP0QQQ&sort=PPP1QQQ&year=PPP2QQQ)。该定义用于准确解释风险，不表示本个人研究项目需要采用银行监管资本框架。
